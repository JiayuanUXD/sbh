# 顾问卡电话高亮与扫码拨打浮层设计规范

## 1. 目标与背景

在楼盘详情页与房源详情页的右侧决策区中，商办顾问卡（`AdvisorCard`）承担了用户与平台顾问直接电话联系的核心路径。
为了强化联络行动的直觉性并提升桌面端到移动端的流转体验，进行如下升级：

1. **去冗余**：去除“客服电话”前缀标签，信息层级更直接；
2. **强化呈现（Highlight）**：电话号码字号提升至 16px、字重 600、采用等宽字体 `sf-num` 与高对比墨黑色，交互态（hover/focus）过渡至品牌强调色；
3. **右侧扫码拨打（QR Dialing）**：
   - 卡片右侧常驻约 48px × 48px 微型二维码及“扫码拨打”微标签；
   - 二维码编码标准 URI `tel:<号码>`，手机原生相机、微信等扫一扫即可直接唤起系统拨号；
   - 鼠标悬停（Hover）或键盘聚焦时，无缝浮现 120px 高清无损放大气泡（Popover），提供更远距离的扫码体验与清晰指引。

---

## 2. 交互与视觉规范

### 2.1 卡片布局
`.advisor-card` 采用三段式水平排布（`align-items: center`）：
* **左侧**：44px 顾问平台虚拟头像（圆形浅蓝底 + `顾问` 字样）；
* **中间（Body）**：
  * 第一行：`商办顾问`（14px, font-weight: 600）；
  * 第二行：电话高亮行（16px, font-weight: 600, 电话图标 + 号码）；
* **右侧（QR Area）**：
  * 常驻 48px 扫码区；
  * 悬浮浮层（Popover）位于扫码区上方居中或向左偏移，带有柔和阴影与白底卡片。

### 2.2 二维码规范
* **协议内容**：`tel:${phone.cleanNumber}`（如 `tel:13162247666` 或 `tel:4008201234`，去除展示用连字符与空格）；
* **技术实现**：React Server Component 服务端直接输出内联 SVG，无客户端水合与静态资源拉取延迟；
* **容错率**：纠错级别设为 `M`（15%）或 `L`（7%），保证最小版本尺寸与最大黑白块模块尺寸，提升远距扫描灵敏度。

### 2.3 浮层（Popover）设计
* **触发方式**：纯 CSS `:hover` 与 `:focus-within`，移入触发、移出隐藏，渐变动效 150ms；
* **浮层内容**：
  * 顶部：小标题“手机扫码拨打”（13px，加粗，`--color-ink`）；
  * 中部：120px × 120px 高清 SVG 二维码；
  * 底部：电话号码完整展示（14px，等宽，加粗）+ 说明文字“微信或系统相机扫一扫”（11px，`--color-muted`）；
* **无障碍（A11y）**：扫码区具有 `aria-label` 与 `role="region"` / `title`，二维码具有相应 `alt` 或 `aria-hidden`。

## 4. 降级与边缘情况

1. **未配置客服电话（或总开关关闭）**：
   - `phone` 为 null 时，电话行与右侧扫码区同步不渲染，卡片优雅自适应仅展示“商办顾问”。
2. **城市覆盖号码**：
   - 若当前城市（如上海）配置了覆盖电话，二维码自动对齐该号码，确保扫码结果与文字展示完全一致。
3. **窄屏移动端自适应**：
   - 在移动端设备上，用户本身已在手机环境中，直接点击高亮电话即可调起拨号，右侧扫码区在移动端断点（`< 640px`）下可通过样式自动收起或简化。

# 第四阶段审查任务包：生产上线与工程门禁

## 审查范围

- 后台 M8：审计、迁移、安全、生产演练与产品验收
- 前台 F7：性能、安全、生产等价、工程验证与发布回退
- Docker 镜像、CloudBase 部署工作流、健康检查和上线预检

## 执行边界

本任务包只进行代码、配置、文档和自动化验证，不修改业务代码、不部署、不执行生产迁移，也不将 M8/F7 待办标记为完成。

## 验收方法

1. 对照 M8/F7 完成标准检查实际实现与任务证据。
2. 检查迁移索引、预检脚本、容器启动和部署工作流。
3. 检查生产密钥、数据库降级、限流、监控和公开调试路由。
4. 执行类型检查、目标测试、完整单元测试和生产构建。
5. 将发现转化为独立优化工作项。

## 完成条件

- 迁移目录、索引和执行报告一一对应，预检能对漏项确定性失败。
- 生产环境缺少 PostgreSQL 或强密钥时进程拒绝启动。
- CI 在发布前执行锁定版本的安装、lint、类型、测试、构建、迁移预检。
- 发布具备灰度、健康门、回滚和并发迁移保护。
- 询盘限流在多实例间一致且存储有过期回收。
- Core Web Vitals、错误率、询盘成功率和无效供给曝光具备真实采集与告警。
- 删除无业务用途公开路由并建立生产安全头基线。
- M8 生产副本演练、回滚和五角色 E2E 有可追溯证据。

### 一个容易误判的坑（记下来免得下次自己吓自己）

`curl -sL "$P/shanghai" | grep -c '这个地址不存在'` 返回 **1**，但页面完全正常。
原因是 App Router 把 not-found 插槽序列化进了**每个页面**的 RSC flight payload：

```
\"notFound\":[[\"$\",\"div\",null,{\"className\":\"empty-state\",\"children\":[[\"$\",\"p\",null,
{\"className\":\"empty-state__title\",\"children\":\"这个地址不存在\"}]...
```

它不渲染。Playwright 的 `expect(page.locator('body')).not.toContainText(...)`
查的是**渲染后的文本**，不受影响；但**用 curl + grep 查 HTML 源码会假阳性**。
刚给 `sale-channel.spec.ts` 加的那条断言用的是前者，安全。

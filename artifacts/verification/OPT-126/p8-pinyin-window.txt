OPT-126 后续：拼音「窗口」匹配 + 去多余限定词（用户反馈：搜「上海 zhongxin」搜不到上海中心）
本地 dev，独立库 sbh_dev_search_pinyin，种子数据（含 上海中心 / 上海国金中心，二者都没有在租房源），2026-11-03。

线上复现（改动前，只读）：「上海 zhongxin」469 条，「上海中心」82 条——拼音词没起作用，放宽后只剩「上海」撑结果。

原因（两层）：
  1. 拼音只支持「整个名字的拼音」或「名字拼音的开头」；zhongxin 是 shanghaizhongxin 的后半截，两种都不命中，原样去 ILIKE。
  2. 即使解析成「上海中心」，词项是 [上海, 上海中心]：上海中心没有在租房源，房源 AND 失败，放宽先丢掉实体词，退化成「上海」；
     楼盘检索只取第一个词项「上海」，也是泛泛的上海楼盘。

  guojinzhongx     => 上海国金中心（最后一个音节只打一部分也行）
  陆家嘴 zhongxin  => 楼盘「上海中心」（上下文看所属商圈 parentName），房源按「陆家嘴」放宽
  上海 xin         => 行为不变：xin 只有 3 个字母，不做窗口匹配，放宽后忽略「xin」
  hongxin          => 0 条：不能从音节（zhong）中间开始
  shanghaizhongxin / 上海中心 => 1 条，行为不变（整词全拼 / 名称命中，优先级高于窗口）

# OPT-118 验证证据：资讯数据口径与脚本

8 篇资讯里所有数字的来源。数据取自 2026-10-16 线上公开 API（匿名可读），**只读、不写**。

## 复现

```bash
python3 -I fetch_data.py                    # 拉 locations / buildings / listings 到 /tmp/opt118-data/（约 73 次请求，每次 500 条，间隔 0.4s）
python3 -I analyze_overview.py              # 各区 / 商圈 / 面积段 / 小面积 统计
python3 -I analyze_terms_and_areas.py       # 商圈排行（≥150 条）、押付与租期占比、共享办公、预算反推
```

`output_*.txt` 是 2026-10-16 当天的运行结果，文章里的数字都能在这里对上。

## 筛选条件（与前台「有效供给」口径对齐）

`publicationStatus=published` 且 `reviewStatus=approved` 且 `businessType=lease`，共 36,471 条，与前台列表页「共 36471 套」一致；
其中 36,427 条按「元/㎡/天」报价（统计价格用），44 条共享办公按「元/工位/月」报价（单独统计）。

## 与前台「有效供给」对账（回应 Codex 评审 P1）

匿名 REST 无法完全表达前台的有效供给：`Listings.access.read` 已说明「被生效举报冻结」表达不成 where，被举报暂停的房源匿名仍可读。
所以取数脚本额外加了 `supplyVisibilityHold = normal`，并新增 `reconcile_with_frontend.py`：把 REST 结果与前台列表页（走统一有效供给服务）的总数、各区计数逐项对账，不一致就退出码 1。

- **取数当时（2026-10-16 上午）**：REST 总数 36,471 = 前台「共 36471 套」；各区前台计数（黄浦 6,740 / 静安 5,255 / 徐汇 6,219 / 长宁 1,891 / 浦东 5,248 / 虹口 3,266 / 普陀 1,675 / 杨浦 1,856 / 闵行 1,323）与 REST 逐区一致（差的几条正是 44 条按工位计价的共享办公，文章里单独统计）。
- **下午复核**：`output_reconcile_with_frontend.txt`，总数 33,892 与前台一致，各区逐项一致。

对得上，说明两个时点上都没有「REST 能读到、前台却不展示」的房源，文章里的数字与前台有效供给同口径。

## ⚠️ 供给当天就变了：文章数字是上午的快照

房源由第三方同步，**同一天内供给就在变**。上午取数到下午复核之间，静安区在租房源从 5,255 条降到 2,676 条（减少 2,579 条，其余各区不变），全市 36,471 → 33,892。
影响（下午数据见 `output_*_refetch_afternoon.txt`）：

- 全市总数、按「元/㎡/天」报价的条数（36,427 → 33,848）、有房源的楼盘数（2,413 → 2,406）、各价格 / 面积 / 付款方式占比小幅变化；
- 静安区：条数、P75（6.04 → 6.38）、楼盘数、小面积条数（705 → 395）；
- 商圈排行：南京西路 2,310 条 / 5.19 → 799 条 / 6.38，静安寺 573 条 / 5.95 → 397 条 / 4.93，昌平路、新闸路、彭浦、老北站不再满足「≥150 条」，达标商圈由 61 个变成 57 个；
- 仲益大厦（上午 764 条）已不在前三十位。

文章里写的都是「截至 2026 年 10 月 16 日」的快照，对取数当时的前台是准确的，**但与现在的前台已经对不上**。文章是草稿，合并代码不会发布它们；**发布前要么按最新数据重算（跑上面三个脚本）、要么在正文里明确标注取数时点**，不要直接发。

## 已知口径限制（文章里已向读者说明）

1. **挂牌价，不是成交价。**
2. **按房源条目统计**，同一楼盘条目多则权重大（例：南京西路 2,310 条里，仲益大厦一栋就有 764 条）。
3. **月租按日单价 × 30 折算。**
4. **`seats` 字段不可用**：36,424 条里面积 ÷ 工位数恒等于 5，是按面积推算出来的，不是真实工位数，文章没有使用。
5. **`spaceDetails.efficiencyRate`（得房率）高度集中在 70%**（p10=65、p90=75），可能带默认值，文章只说「大致 65%–75%」，没有当数据结论用。
6. **`costTerms.propertyFeeInclusion` / `invoiceStatus` 全部为空**：文章据此提醒读者「站内报价均未标明是否含物业费、能否开票」。
7. 共享办公只有 44 条（静安 14 / 黄浦 10 / 浦东 7 / 长宁 5 / 普陀 4 / 徐汇 3 / 虹口 1），文章已标注样本小。

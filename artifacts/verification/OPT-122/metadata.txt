# OPT-122 验收 metadata 实测（生产模式 `next start -p 3721`）

- 日期：2026-10-20（验收复测）
- 命令形态：`curl -s http://localhost:3721/<path>`，抓取 title / robots / canonical

## /shanghai/search?q=虹桥

```html
<title>搜索 · 上海 · 商办租赁</title>
<meta name="robots" content="noindex, follow"/>
<link rel="canonical" href="http://localhost:3721"/>
```

注：搜索页未显式设置 canonical，`rel=canonical` 输出来自根布局默认值（站点根）。页面为 noindex，canonical 无实际搜索语义影响，记为观察项。

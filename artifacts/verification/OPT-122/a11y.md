## ARIA

- **结果计数播报**：`<p class="ls-head__sub" aria-live="polite">共 N 条结果</p>`，HTML 实测存在（验收记录 metadata.txt 同期抓取）。
- **联想 combobox**（WAI-ARIA 1.2 combobox pattern）：
  - input：`role="combobox"` + `aria-autocomplete="list"` + `aria-expanded` + `aria-controls` + `aria-activedescendant`（激活项同步）；
  - 列表：`role="listbox"` + `aria-label="搜索建议"`；选项 `role="option"` + `aria-selected`；
  - E2E 以 `getByRole('listbox'/'option')` 定位成功，证明角色树对辅助技术可见。
- **tab 导航**：`<nav aria-label="搜索结果类型">`，当前 tab 带 `aria-current="page"`（E2E 断言）。
- **图标**：全部 `aria-hidden="true" focusable="false"`。

## 对比度

- 文本用语义变量：`--ink` / `--ink-2` / `--ink-3`（正文/次级/弱化），链接 `--accent-link`，激活项底色 `--bg-hover`；均为设计系统既有 token，未引入自定义颜色。
- 联想下拉：`--bg` 底 + `--line` 描边 + `--shadow-lg` 投影，与站点既有浮层（导航抽屉）同一套材质。

## 动效

- 联想出现/消失为即时显示（无动画），不引入眩晕风险；展开动效仅在 `<1280` 顶栏覆盖层（既有 `header-search-in`，220ms），`prefers-reduced-motion` 由全局通配规则兜住（既有机制）。

## 已知限制

- 联想列表鼠标用 `onMouseDown` 抢在 blur 前导航；触屏点击同样走 pointer 事件链，无聚焦丢失问题。
- 零结果页的「提交找房需求」走既有 `InquiryModal`，其内部焦点陷阱为本期之前实现，未重新验收。

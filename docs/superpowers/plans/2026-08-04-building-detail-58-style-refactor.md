# 楼盘详情页重构方案（对标 58 商办详情结构）

- 日期：2026-08-04
- 分支：`feat/frontend-page-opt`
- 参考：58 商办楼盘详情页（保利西岸中心截图）
- 状态：**方案 + 演示页评审中**（演示路由 `/dev-story/building-detail-demo`，开发与生产均可见，搜索引擎不收录）

## 1. 目标与边界

把 C 端楼盘详情页的信息层级重排为 58 商办的「决策效率」结构：首屏即
画廊 + 价格/供给/关键参数决策面板，房源区带粘性右栏，位置区灰底成带。

边界约束：

- **只动表现层**。楼盘详情视图模型、供给快照等数据契约与 `src/lib/frontend/` 查询逻辑一律不改。
- **复用现有组件资产**，不引新界面库；视觉语言沿用奶油+金设计系统
  （铜色、纸色、画布色等设计变量），只借 58 的结构，不抄 58 的配色。
- 生产页（`buildings/[slug]/page.tsx`）在演示评审通过前**保持现布局**，
  通过后一次切换并删除旧布局组件。

## 2. 58 结构提取（截图，自上而下）

1. 面包屑
2. 标题行：楼盘名 + 分享
3. 首屏两栏：左画廊（主图+缩略图+箭头）｜右决策面板（大号起价+免责声明、
   可租面积/在租套数双统计、地址/地铁/物业/开发商/建筑面积字段行、顾问卡+电话按钮+二维码）
4. 房源区两栏：主列（面积/价格筛选 + 表格：图|面积|单价|总价|特色 +
   「查看更多」）｜右粘性栏（迷你摘要卡、免费咨询顾问卡、折扣房源订阅、热门楼盘）
5. 楼盘参数（双列字段网格 + 配套标签）+ 楼盘特色文字
6. 位置及周边（全宽灰底：地图 + 右侧 交通/餐厅/银行/酒店 配套页签；下方周边楼盘横滑）
7. 猜你喜欢卡片网格
8. 页脚

## 4. 与 58 的取舍

- **不做二维码**：无个人顾问微信入口，询价留电弹窗已覆盖该转化路径。
- **不重复顾问条**：58 在首屏右栏与首屏下方重复展示顾问；我们首屏右栏 +
  右粘性栏各一处，不再加全宽重复条。
- **无评分体系**：58 的「4.5 分/㎡/天」实为起价大字；我们用铜色大字起价 +
  等级徽章 + 核验时间戳替代评分位。
- **位置区不做全宽出血**：容器内灰底圆角成带，避免按视口宽度出血带来的横向滚动问题。

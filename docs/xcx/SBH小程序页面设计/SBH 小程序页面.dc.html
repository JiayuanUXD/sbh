按 miniprogram-design.md 的 v2 地基执行：灰底 #f2f2f4 + 白色圆角卡块（radius 8 / 左右 margin 12 / 块间 10 / 内 padding 14），字号阶 15·13·11，中文系统字体、数字 Geist 拉丁子集并全程 tabular-nums。色彩不在 v2 反转范围内：标签零色相，价格用主文字色，蓝色只给可交互元素。

D1′ 移动优先重做布局 D2 找房主链路 + 楼盘体系 D3 纯 C 端 tabBar 4 项 · 无中央凸起 图片为占位
圆角规范 · 三档，按「能不能点」和「在哪里点」分
标签 3px 只读信息，不可点：房源标签、状态标记、「真实供给」背书。圆角最小，读起来像文字而不像按钮。
矩形 6px 默认档。可点但受容器约束的一切：卡内 CTA、半屏弹层的提交、筛选 chip、面积段与城市格、输入框、搜索按钮。与卡块的 8px 同族，贴着容器边界。
胶囊 999px 只给底部固定操作栏里的主 CTA（预约看房、找顾问问楼、约看这 3 套）。那一栏不是卡块、与图标并排，胶囊让主动作从栏里浮起来。一屏最多一个。
判据一句话：不可点 → 3px；在卡里 → 6px；在底部操作栏 → 胶囊。因此留资弹层的「提交」是 6px（它在半屏卡内），详情页的「预约看房」是胶囊（它在固定操作栏里）。图片一律 6px。

未拿到 .agent/design-system.md：ink 三档、--line、accent 按 Apple 中性色板取值（#1d1d1f / #6e6e73 / #86868b / #e5e5e7 / #0071e3）。若与真实 token 有差，给我文件我全局替换。

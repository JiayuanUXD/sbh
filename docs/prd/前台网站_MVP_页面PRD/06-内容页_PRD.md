# FP-06 内容页 PRD

> 路由：`/pages/[slug]`  
> 优先级：P1  
> 状态：待确认

## 1. 页面目标

内容页承载办公指南、服务介绍、关于我们、隐私政策等可运营内容，为自然搜索、品牌信任和咨询转化提供稳定落地页。

## 2. 内容类型

- 办公选址指南。
- 区域/商圈介绍。
- 办公解决方案与服务说明。
- 关于我们。
- 隐私政策及必要法律内容。

不同内容类型可复用同一路由和渲染器，但通过模板或模块白名单形成差异。

## 3. 页面结构

- 全局导航与面包屑。
- 标题、摘要、发布日期或更新时间（适用时）。
- 主视觉（可选）。
- 结构化正文。
- 目录（长内容可选）。
- 相关文章或相关区域/房源（可选）。
- 文末咨询 CTA（隐私政策等法律页面除外）。
- 全局页脚。

## 4. 内容模块

MVP 白名单：

- 标题、段落、引用、列表。
- 图片与图注。
- 分隔线。
- 双栏图文。
- 数据/亮点卡。
- CTA。
- 相关文章。
- 相关有效房源或楼盘入口。

正文不得注入任意脚本、iframe 或未批准 HTML。外链需明确样式和安全属性。

## 5. 发布与数据规则

- 只读取 Payload Pages 当前已发布版本。
- 草稿、历史版本、逻辑删除或禁用内容不得由直链访问。
- 内容引用的房源必须在请求时通过统一有效供给服务；失效引用应自动隐藏或替换为中性找房 CTA。
- 内容引用的楼盘必须满足楼盘公开规则。
- slug 唯一且修改时需要明确重定向策略；MVP 上线后不得静默更改已收录 slug。

## 6. SEO

- 每页可配置 title、description、canonical、OG 图片。
- 标题层级从单一 H1 顺序展开，不以字号模拟层级。
- 文章型内容可输出 Article 结构化数据；服务页不错误标记为 Article。
- 页面正文、导航和结构化数据使用一致的发布日期与作者策略。
- 隐私政策等必要页面可索引，但不得附加营销型相关推荐。

## 7. 页面状态

| 状态 | 表现 |
|---|---|
| 已发布 | 渲染白名单内容模块 |
| 草稿/不存在 | 404 |
| 未支持模块 | 跳过并记录告警，不让整页崩溃 |
| 相关房源失效 | 隐藏失效卡片，保留内容主体 |
| 主图失败 | 固定比例占位，不影响正文 |

## 8. 可读性与可访问性

- 正文行宽建议 680–760px，长段落有明确节奏。
- 图片包含 alt；纯装饰图片使用空 alt。
- 目录支持键盘并正确处理吸顶导航偏移。
- 引用、表格和列表具有语义，不使用纯视觉 div 替代。

## 9. 埋点

- 内容页浏览。
- 目录点击。
- 相关文章点击。
- 相关房源/楼盘点击。
- 文末咨询打开。

事件记录内容 ID 和内容类型，不发送正文或 URL 中可能存在的个人信息。

## 10. 验收标准

- 当内容处于已发布状态时，系统应按白名单模块稳定渲染并生成完整 Metadata。
- 当内容为草稿、删除或不存在时，系统应返回 404 且不得泄露预览内容。
- 当正文引用的房源失效时，系统应在有效供给失效窗口内撤销该卡片。
- 当 CMS 包含未支持模块时，系统应保持其余内容可读并产生可追踪告警。
- 当使用键盘或屏幕阅读器时，页面标题层级、目录、图片和链接应具有正确语义。
- 当页面在 375px 视口展示长标题、列表和图片时，不应出现横向溢出。

## 11. 非目标

- 任意自定义 HTML/JavaScript。
- 用户评论。
- 多语言内容管理。
- 所见即所得的前台编辑。

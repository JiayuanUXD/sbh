## 1. 文档用途

本目录将前台 MVP 拆成可以独立开发、设计走查和验收的页面级 PRD。页面文档定义用户可见结果，不替代总体业务规则和技术架构。

如页面文档与上位文档冲突，优先级如下：

1. 后台 PRD 中的数据不变量和统一有效供给口径；
2. `frontend-mvp/requirements.md`；
3. `frontend-mvp/design.md`；
4. 本目录页面 PRD。

## 3. 所有页面的共同验收门槛

- 所有房源卡片、数量、聚合、详情和推荐均来自同一统一有效供给服务。
- 中文不存在乱码、截断占位符或中英文标点异常。
- 价格同时展示数值、币种和单位，不跨租售类型、币种或单位错误比较。
- 375、768、1440、1920 四档视口无横向溢出、遮挡或不可操作控件。
- 核心流程支持键盘操作，正文与控件满足 WCAG 2.2 AA 对比度目标。
- 加载、空、错误、无权限或内容失效状态不得伪装为正常数据。
- 页面不向浏览器输出审核、举报、商户资质、内部电话等非公开字段。
- SEO、缓存、隐私、埋点和性能要求执行 `design.md` 的统一策略。

## 4. 交付与验收方式

每个页面按以下顺序交付：

1. 数据契约与状态测试；
2. 桌面和移动端实现；
3. 功能验收；
4. 浏览器视觉走查；
5. 可访问性、性能和 SEO 检查；
6. 修复后由验收人关闭该页面 PRD 的未通过项。
